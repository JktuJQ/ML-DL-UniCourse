# ML/DL Uni Course

This repository contains all of my seminars and homework assignments,
completed during my university course on ML/DL.
They are usually stored in Jupiter Notebook format because it's very convenient.

While most of the text and code is my own,
I still owe a debt of gratitude to my [teacher](https://github.com/ShadarRim)
for developing the [course](https://github.com/ShadarRim/25AIMEPhI) as a whole.

# Classic ML

In this section assignments usually contain from-scratch implementation of the algorithm
and Kaggle contest, where I try to use those models to solve some tasks.

It covers basics of ML - [regression](LinearRegression), [classification](LogisticRegression), [clusterization](Clusterization) and [ensambling](EnsambleMethods).
You can find more specific information in the READMEs of respectable folders.
