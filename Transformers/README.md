# Research on Transformers 

This folder contains my work on **transformers**.

## Semantic classification

Transformers are the type of model that are primarily used for sequence processing.
The most common type of those sequences is text.

In this [file](semantic_classification.ipynb) I use BERT that was distilled into smaller model
to analyse user reviews of different films and determine whether they are positive or not.
Such task is called *semantic classification*.
